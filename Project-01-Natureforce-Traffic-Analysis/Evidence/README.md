# Investigation Evidence

This folder contains screenshots collected during the Natureforce network traffic investigation.

## Evidence Categories

1. DHCP – Client IP and MAC identification.
2. NBNS – Hostname identification.
3. SMB2 – Windows file-sharing traffic.
4. Kerberos – Domain authentication analysis.
5. TCP – Connection establishment.
6. HTTP – Suspicious executable download.
7. SHA-256 – Extracted file hash verification.

All screenshots are intended to support the findings documented in this project.

**Note:** Original PCAP files and suspicious executable samples are retained locally and are not included in this public repository.
