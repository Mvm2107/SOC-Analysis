# Project 01 – Natureforce Traffic Analysis

## Overview

A hands-on network traffic investigation using Wireshark
to investigate suspicious network communication involving
a Windows client.

## Tools Used
- Wireshark
- PowerShell

## Investigation Areas
- DHCP analysis
- NBNS hostname identification
- SMB2 traffic analysis
- Kerberos authentication analysis
- TCP connection analysis
- HTTP file transfer investigation
- SHA-256 hash calculation

## Project Status
Core traffic investigation completed.

Static malware analysis is planned as a separate future phase.
